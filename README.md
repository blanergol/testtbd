# Командная память

Здесь команда хранит то, что обычно теряется в чатах: решения, разборы инцидентов,
повторяемые процедуры и просто заметки. Это обычные markdown-файлы — их можно читать
и править чем угодно, а TeamBrains поверх них умеет искать и отвечать со ссылками.

## Как этим пользоваться

- **Своё** пишите в `workspaces/<ваша-папка>/`. Чужие папки трогать не нужно и нельзя.
- **Общее** (`shared/`) меняется через «Предложить команде»: изменения увидит и согласует команда.
- **Не удаляйте записи молча.** Если решение устарело — отметьте его как устаревшее и
  укажите, какая запись его заменяет. Тогда поиск перестанет выдавать старое как текущее,
  но история останется.
- Папки `_archive/` не индексируются: туда попадает то, что убрали из памяти.

## Что где лежит

| Путь | Что это |
|---|---|
| `workspaces/<человек>/summaries/` | итоги работы, которые сохранил агент или вы сами |
| `workspaces/<человек>/notes/` | заметки |
| `workspaces/<человек>/assets/` | картинки и вложения |
| `shared/decisions/` | решения уровня команды |
| `shared/runbooks/` | повторяемые процедуры |
| `.teambrains/` | настройки: список ролей, словарь тегов, карточки людей |
